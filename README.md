# Delivery Partner Landing Page

This is a simple and responsive landing page created using **HTML and CSS**.  
The project demonstrates the use of **Google Fonts**, **CSS Grid**, and **parallax background scrolling effect** using `background-attachment: fixed`.

## Features
- Clean and simple UI design
- Parallax scrolling background effect
- Google Fonts integration
- Full-screen sections using CSS Grid
- Multiple sections with different background images
- Responsive text alignment and styling

## Sections in the Website
1. **Delivery Partner**
   - Intro section for delivery partner information.

2. **Benefits of Being a Delivery Partner**
   - Flexible working hours  
   - Extra income opportunities  
   - Be your own boss  
   - Access to large customer base  
   - Growth opportunities  

3. **How to Become a Delivery Partner**
   - Sign up online  
   - Submit required documents  
   - Attend orientation  
   - Start delivering and earning  

## Technologies Used
- HTML5
- CSS3
- Google Fonts

## Learning Purpose
This project was created to practice:
- CSS background properties
- Parallax scrolling effect
- Web page layout using Grid
- Font styling using Google Fonts
